# Applications

Application workspaces live here. Each application must own its runtime entrypoint, configuration, tests, health checks and deployment contract.

Planned:
- `api/`: authenticated Node.js API.
- `worker/`: asynchronous jobs and provider orchestration.
- `storefront/`: future location for the current `source/` frontend after a verified Cloudflare Pages migration.

Do not create duplicate app source trees during migration.
